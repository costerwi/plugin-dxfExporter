# plugin-dxfExporter
Abaqus CAE plugin to export the currently displayed object in DXF format

## Installation instructions

1. Download and unzip the [latest release](https://github.com/costerwi/plugin-dxfExporter/releases/latest)
2. Double-click the included `install.cmd` or manually copy files into your abaqus_plugins directory
3. Restart Abaqus CAE and you will find the tool in the menu Plug-ins > Tools > DXF Export...
